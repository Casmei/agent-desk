# 0014. Projeto aberto com licença MIT

- **Status:** Aceita
- **Data:** 2026-11-26
- **Quem decidiu:** o dono do projeto decidiu que o projeto é aberto; Claude escolheu a licença MIT.

## Contexto

O objetivo é que qualquer comerciante pequeno ou médio possa ter um agente no WhatsApp, instalando e rodando por conta própria. Isso pede código público e uma licença clara.

## Decisão

O projeto é **aberto** e usa a licença **MIT**, com titular "Tiago de Castro" e ano 2026. O README é voltado a quem quer instalar e rodar por conta própria.

## Alternativas consideradas

- **Apache-2.0:** inclui concessão explícita de patentes, mas é mais longa e o projeto não precisa dela.
- **AGPL:** obrigaria quem oferece o sistema como serviço a abrir as alterações, o que desencoraja adoção.
- **Código fechado:** contradiz o objetivo do projeto.

## Consequências

- Qualquer pessoa pode usar, modificar e redistribuir o código, inclusive comercialmente.
- Não há garantia sobre o software, e o repositório não deve conter segredos.
